# jik

## Run

```sh
cargo run --release
```

jik runs in the system tray.
Use its menu to ask now, pause, start with Windows, or quit.

On first run, jik creates `questions.toml` (your questions) and `config.toml` (settings) next to the executable.
Edit them and restart jik.
Answers go to `answers.jsonl` in the same folder.
